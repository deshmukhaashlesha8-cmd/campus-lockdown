# Campus Lockdown

*A normal college day was never part of the plan.*

Campus Lockdown is a 2D top-down pixel-art game built in Godot where a familiar college campus turns into a place full of locked doors, strange clues, and unexpected surprises. Explore classrooms, the library, the computer lab, and the admin office while trying to figure out what is happening inside the campus.

## What's inside?

* Top-down pixel-art gameplay
* Interactive classrooms and campus rooms
* Door-based room transitions
* Computer lab, library, and admin office environments
* Custom-made assets designed for the game
* Built using **Godot 4.7** and **GDScript**

## Controls

* **W / A / S / D** — Move
* **E** — Interact / Open doors
